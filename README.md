# Innovative Global Impact — Website

Working files for the IGI nonprofit website redesign (WordPress block theme, hosted on AWS Lightsail/Bitnami with GiveWP for donations).

## Contents

| Folder | What it is |
|---|---|
| `igi/` | The custom WordPress block theme — the deployable codebase (templates, parts, patterns, assets). |
| `claude-design/` | Design source: page mockups, shared CSS, and block-markup exports used to build the theme. |
| `IGI-website-handoff/` | Project brief, design prompt, logos, and photography assets. |
| `preview/` | Local render harness output (HTML renders; generated screenshots are gitignored). |

Not committed: server keys, zip archives, theme backups, and generated PNG screenshots (see `.gitignore`).
